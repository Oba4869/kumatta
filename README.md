# くまった

**走りたくなる、その一瞬をこらえろ。**

クマに出会った瞬間の「とっさの判断」を、ゲームで体に覚えさせるWebアプリです。
反射神経といっても「速く逃げる」ではありません。逃げたくなる衝動をこらえて、**正しい行動をすばやく選ぶ**力を鍛えます。

## なぜ作ったか

- クマの出没と人身被害が全国で増えていて、登山者だけでなく通学路でも出会う可能性がある
- 対処法は「走らない・背中を見せない・ゆっくり後退」と知っていても、本番では体が動かない
- 知識を読むだけでなく、**手を動かして何度も練習できる**教材がほしかった

## 遊び方

1. **山を選んで出発**：条件（晴れ・沢沿い・夕方・強風・霧・北海道）は毎回変わる。道具を2つ選ぶ
2. **夜の森を一人称で進む**：霧の夜の森を、懐中電灯の明かりだけで避難小屋まで進む。マウス（スマホは画面をドラッグ）で見回し、WASD（スマホは左スティック）で移動。Shift で走れるが、足音で気づかれる。クマが近いほど心臓の音と画面の赤みが強くなる。V で見下ろし視点に切り替えられる
3. **クマに見られたら**：走らず、目を逸らさず、クマを画面に捉えたまま S でゆっくり後ずさり。警戒が下がればクマは興味をなくす。目を逸らす・背中を見せる・走ると、追撃ゲージがたまって突進される
4. **威嚇されたら**：クマが後ろ足で立ち上がり、唸りながら近づいてくる。数メートルまで引きつけて撃退スプレー（Space）。間に合わなければ防御姿勢（E 長押し）で首を守る
5. **結果**：S〜Cのランクと、公式資料にもとづく「ふりかえり」が出る

## 主な機能

| 機能 | 内容 |
|---|---|
| 3Dの夜の森 | Three.js。左上のマップに、見つかったクマの位置が出る。霧、月明かりの筋、懐中電灯の光の筋、草や木の揺れ、ホタル、雪や落ち葉。ブルーム・色調補正・フィルムグレイン・危険時の赤い色ずれのポストエフェクト。画像ファイルは使わず、テクスチャもその場で生成 |
| クマのAI | 巡回 → 警戒 → 威嚇（立ち上がる）→ 突進。視界・距離・足音・風上のにおいで気づく。子グマに近づくと母グマがすぐ威嚇 |
| 立体音響 | クマの唸り声や足音が、聞こえる方向から鳴る（後ろからの音はこもる）。風・虫・フクロウ・沢の環境音 |
| 6つの山の条件 | 霧で見通しが悪い、夕方はクマが多い、強風は風向きでにおいとスプレーが変わる、沢沿いは足音が届きにくい、北海道はヒグマ（速く、スプレーは3〜4mまで引きつける）。北海道は天気（晴れ・霧・初雪）も変わる |
| 道具 | クマ鈴・ラジオ（遠くのクマが離れていく）、撃退スプレー（3回）、リュック・ヘルメット（防御姿勢が早くとれる） |
| 図鑑 | 11種類の生き物（ノーマル〜激レア）。激レアは北海道の霧や初雪の日にだけ出る幻のエゾオオカミ |
| レベルとごほうび | Lv.1〜20。Lv.3でクマの視界表示が消えて難しくなる。Lv.12で金、Lv.15で虹、Lv.20で「頂点」仕様のプレイヤーカード |
| バッジ | 12種類。記録とバッジは正しい行動をしたときだけもらえる |

## 内容の根拠

ゲームの「正解」とふりかえりの解説は、次の公式資料にもとづいています。

- 環境省「クマ類の出没対応マニュアル」
- 環境省「クマ類の保護及び管理に関するレポート（令和6年度版）」
- 林野庁「クマ対策の注意事項」
- 宮城県「ツキノワグマの被害に遭わないために」
- 富山県教育委員会「県立学校におけるクマへの対応について」
- 知床財団「出会った時は（ヒグマ対処法）」
- 兵庫県「イノシシによる人身被害防止について」
- 京都府レッドデータブック2015「ニホンオオカミ」
- 観光庁 多言語解説文データベース「エゾシカ」

> クマの攻撃を完全に避ける方法はないとされています。このゲームでの正解は、被害を小さくできる可能性を高める行動です。

## 素材

- 3Dの森の一部（木・岩・切り株・倒木・茂み・キノコ・花）：Kenney「Nature Kit」（CC0）https://kenney.nl/assets/nature-kit
- クマと動物（ウサギ・タヌキ・エゾオオカミ）の3Dモデル：チームで用意した参考画像から Tripo AI（無料プラン、CC BY 4.0）で生成し、Blender で整えたもの（手順は `tools/bear-models/`）

## 技術スタック

- **React 19 + TypeScript**（Vite）
- **Tailwind CSS v4**（色はCSS変数のデザイントークンに対応。ライト／ダークモード対応）
- スタート画面の絵は画像1枚（WebP）＋SVGの動き。ゲーム内の3D・効果音はすべてコードで生成（Web Audio API）
- 進み具合（レベル・図鑑・バッジ）はブラウザの localStorage に保存（サーバーなし）
- PC・タブレット・スマホ（縦／横）に対応。スマホはタッチ操作（スティックとボタン）

## フォルダ構成

```
src/
├─ App.tsx              画面の切り替え・プロフィールの保存
├─ components/          画面とUI部品
│  ├─ StartScreen.tsx   スタート画面（山の条件・道具選び）
│  ├─ PlayScreen.tsx    プレイ画面の見た目（動きは GameEngine が担当）
│  ├─ ResultScreen.tsx  結果画面（ランク・XP・バッジ・ふりかえり）
│  ├─ DexScreen.tsx     図鑑
│  ├─ PlayerCard.tsx    レベルカード（Lv.12/15/20で見た目が変わる）
│  ├─ RankEmblem.tsx    ランクのメダル
│  └─ Icons.tsx         SVGアイコン
├─ game3d/               3Dゲーム本体
│  ├─ game.ts           ゲームの進行（操作・クマのAI・判定・HUD・結果）
│  ├─ world.ts          森の生成（地形・道・木・草・小屋・霧・月の光）
│  ├─ actors.ts         クマ（立ち上がる骨組み）・登山者・小動物のモデル
│  ├─ materials.ts      輪郭光（リムライト）と風の揺れのシェーダー
│  ├─ post.ts           ポストエフェクト（ブルーム・色調・グレイン・危険演出）
│  ├─ audio3d.ts        立体音響と環境音
│  └─ textures.ts       地面・道・樹皮・毛並みなどのテクスチャ生成
├─ game/
│  ├─ engine.ts         3Dゲームを読み込む入口
│  ├─ swipe.ts          画面中央の大きな文字と、虹・金・銀の演出
│  ├─ scoring.ts        ランク・XP・バッジの判定
│  ├─ feedback.ts       ふりかえり（出典つき解説）の生成
│  ├─ run.ts            次の山（条件・天気・道具候補）の抽選
│  └─ types.ts          型定義
├─ data/                山の条件・道具・図鑑・レベル・バッジ・出典
└─ lib/                 保存（localStorage）と効果音
```

3Dゲームは1秒に60回画面を更新するので、Reactの状態ではなく `Game3D` クラスが WebGL とHUDを直接動かしています。結果だけをReactに返し、スタート・結果・図鑑の画面はReactで描画しています。

## 開発

Node.js 20以上が必要です。

```bash
npm install
npm run dev       # 開発サーバー（http://localhost:5173）
npm run build     # 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果の確認
```

## GitHub Pages で公開する

`.github/workflows/deploy.yml` が入っているので、`main` ブランチに push すると自動でビルドして公開されます。

1. GitHub にリポジトリを作って、このフォルダの中身を push する
2. リポジトリの **Settings → Pages** を開き、**Source** を「**GitHub Actions**」にする
3. **Actions** タブで「Deploy to GitHub Pages」が緑になったら完了
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べる
